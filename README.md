# FreeFounders

One subscription, one login, two apps: **Tasks** (task automation + HR) and **Assets**
(asset management). Web + Android. Built for Indian businesses.

- Plan and roadmap: [PLAN.md](PLAN.md)
- How to run and test: [CLAUDE.md](CLAUDE.md)

| Service | Stack | Path |
|---|---|---|
| Tasks | Django 6 + DRF, React 18 | `services/tasks` |
| Assets | NestJS 11, React 19, Drizzle | `services/assets` |
